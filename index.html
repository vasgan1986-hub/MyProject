1. Инициировать репозиторий в корне проекта.
    git init
  2. Загрузить изменения на GitHub
    • Указать нужные файла (добавить в индекс)
      git add index.html
    • Задать название коммиту
      git commit -m "second commit"
      • git branch -M main
    • Запустить перенос файлов
      git push
